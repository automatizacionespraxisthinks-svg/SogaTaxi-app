SogaTaxi Conductor

Aplicación para conductores de SogaTaxi S.A.

📱 Android

⬇ Descargar la aplicación
  1. Abre el archivo descargado sogataxi-conductor.apk.
  2. Si el teléfono lo pide, permite Instalar apps desconocidas para el navegador o para Archivos.
  3. Toca Instalar y luego Abrir.
  4. Al entrar, permite la ubicación y elige «Permitir todo el tiempo» con «Ubicación precisa» activada. Permite también las notificaciones y resuelve lo que aparezca en «Falta permitir»: sin eso no llegan las carreras.

El GPS solo se envía con el turno abierto: al cerrarlo deja de enviarse.

Si Play Protect muestra un aviso, toca «Más detalles» → «Instalar de todas formas». La aplicación es de SogaTaxi y no está en la tienda.

🍎 iPhone

Abre esta página en Safari: desde otro navegador no se puede instalar.

  1. Abre conductor.sogataxi.praxisia.org en Safari.
  2. Toca Compartir (el cuadro con la flecha ↑, abajo).
  3. Elige Añadir a pantalla de inicio y luego Añadir.
  4. Abre Conductor desde el icono nuevo, no desde Safari, y permite las notificaciones.
Abrir la aplicación

Necesita iOS 16.4 o más reciente. Con la aplicación abierta deja el teléfono en el soporte con la pantalla encendida: iPhone no despierta la pantalla sola para una oferta.
